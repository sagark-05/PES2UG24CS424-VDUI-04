# VDUI Lab – Visualization and Data User Interfaces

This repository contains the lab exercises, Jupyter Notebooks, and datasets completed as part of the **Visualization and Data User Interfaces (VDUI)** course at **PES University**.

## Course Details

- **Course:** Visualization and Data User Interfaces (VDUI)
- **Course Code:** UE24CS342AA9
- **University:** PES University
- **Program:** B.Tech – Computer Science and Engineering

## Repository Contents

The repository includes:

- **Jupyter Notebooks (`.ipynb`):** Implementations of VDUI lab exercises.
- **Datasets:** Data files used for analysis and visualization.
- **PPT-wise Exercises:** Lab exercises organized according to the corresponding course PPTs.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## How to Run

1. Clone the repository.
2. Open the project folder in Jupyter Notebook or VS Code.
3. Install the required Python libraries.
4. Open the desired `.ipynb` file.
5. Ensure the corresponding dataset is available at the path referenced in the notebook.
6. Run the notebook cells sequentially.

## Purpose

This repository serves as a collection of practical exercises to understand data visualization techniques, exploratory data analysis, and effective visual representation of data.
